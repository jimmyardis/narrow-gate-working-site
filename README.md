# Narrow Gate — working HTML site

Open `index.html` in a modern browser, or upload the contents of this folder to a static host such as GitHub Pages. No build step or dependencies are needed. For local HTTP preview with Node.js, run `npm run dev`.

The site includes 47 curated source-linked entries: essays, conversations, archival material, commonplace selections, and project profiles connected to Vince Graham. Search, category filters, sorting, and pagination run locally. External articles require internet access; fonts, artwork, project photographs, and the supplied manuscript are included locally.

Edit `archive-data.js` to update entries, `index.html` for featured selections, and `styles.css` for layout. `sequence-as-canon.html` links to the supplied complete DOCX manuscript; publication status has not been independently established.

See `SOURCES.md` for attribution and source URLs. The visual composition closely follows the supplied mockup with responsive HTML and live text. The decorative hero is recreated artwork; featured content and photographs are drawn from documented sources.

This package is ready to host. It has not been deployed to the existing GitHub Pages site.
